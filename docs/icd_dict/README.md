# ICD 字典数据集（手术 + 疾病编码）

本目录是 DeepAudit 编码标准化（standardization）维度质控规则的**字典基础数据**，
用途有二：

1. 灌入 `icd_dict` 表（V1__init_schema.sql 已建表，目前为空）
2. 调用 embedding 模型生成 `name_embedding`，落 pgvector，
   作为后续"编码-名称一致性"、"近似手术名→标准编码"等向量召回任务的索引

---

## 数据来源与版本

| 文件 | 类别 | 版本 | 来源 | 条数 |
|------|------|------|------|------|
| `icd9cm3_common.jsonl` | 手术与操作分类（icd9cm3） | 国家临床版 3.0（国卫办医函〔2020〕438号） | 公开规范+临床常见术式整理 | ~150 |
| `icd10_common.jsonl` | 国际疾病分类（icd10） | 国家临床版 2.0 / GB/T 14396-2016 | 公开规范+常见疾病整理 | ~70 |

> ⚠️ **数据完整性声明**
> 完整 ICD-9-CM-3 V3.0 共 8000+ 条、ICD-10 V2.0 30000+ 条。本目录是**精选常见编码集**，
> 仅用于 MVP 阶段验证编码维度规则与向量召回流程。**正式生产部署前**，
> 应以国家卫健委 / 国家医保局发布的权威全量文件覆盖：
> - ICD-9-CM-3 国家临床版 3.0：国卫办医函〔2020〕438号 附件
> - ICD-9-CM-3 医保版 2.0：[国家医保编码标准库](https://code.nhsa.gov.cn/jbzd/public/dataOperationSearch.html)
> - ICD-10 国家临床版 2.0：国家卫生健康委统计信息中心
>
> 现有条目按"覆盖各章节大类（4 位主类码）+ 临床高频术式（部分到 6 位末端码）"的策略筛选，
> 编码格式遵循 V3.0 规范 `XX.XX` 或 `XX.XXXX`。

## 字段定义（每行一条 JSON 对象）

```json
{
  "code":          "47.0900",
  "name":          "其他阑尾切除术",
  "category":      "icd9cm3",
  "version":       "national_clinical_v3.0",
  "chapter":       "09",
  "chapter_name":  "消化系统手术",
  "block":         "47",
  "block_name":    "阑尾手术",
  "aliases":       ["开腹阑尾切除", "经典阑尾切除术", "阑尾切除"],
  "embedding_text": "47.0900 其他阑尾切除术 开腹阑尾切除 经典阑尾切除术 阑尾切除"
}
```

| 字段 | 必填 | 用途 |
|------|------|------|
| `code` | ✅ | 写 `icd_dict.code`；UNIQUE(code, category, version) |
| `name` | ✅ | 写 `icd_dict.name`；UI 展示 |
| `category` | ✅ | `icd9cm3` 或 `icd10`；写 `icd_dict.category` |
| `version` | ✅ | 写 `icd_dict.version`；不同版本可并存 |
| `chapter` / `chapter_name` | 选 | 后续做"按章节统计/过滤"时用，目前不入表 |
| `block` / `block_name` | 选 | 同上，三位数大类（如 47=阑尾） |
| `aliases` | 选 | 同义词/俗称数组，**核心提升向量召回率** |
| `embedding_text` | ✅ | 预拼好的 embedding 语料（code + name + aliases 拼接） |

> `embedding_text` 不入表，仅给离线 embedding 任务读；生成的 768 维向量写入
> `icd_dict.name_embedding`（V1__init_schema 当前是 1024，V2 已 ALTER 到 768 适配 Gemini）。
> 切换 DeepSeek 后该列实际未填充——后续若启用向量召回，需选定 embedding 模型并对齐维度。
