❯ MCP能否在项目运行过程中由LLM调用？比如现在假设有一个生成测试pdf的按钮，gemini 
   会调用这个吗                                                                 

● 不能，这里有一个根本的架构误区值得说清楚。

  ---
  MCP 的边界

  MCP 是 AI 助手客户端（Claude Code / Claude Desktop） 调用外部工具的协议。

  Claude Code (MCP client)
      ↕ stdio
  MCP Server (sample-pdf-generator)

  Gemini 不是 MCP 客户端。 它是你 Spring Boot 里通过 langchain4j 调用的
  LLM，不懂 MCP 协议，也不会去连 MCP server。

  ---
  你的应用场景实际的架构

  浏览器按钮 → Spring Boot → langchain4j → Gemini
                                  ↓
                           @Tool 注解方法
                                  ↓
                         调用 Python 脚本 / 直接生成 PDF

  Gemini 要调用工具，走的是 langchain4j 的 @Tool 机制（底层是 Gemini 的 Function
   Calling API），不是 MCP。

  ---
  两者分工

  ┌────────┬──────────────────────────────────┬─────────────────────────────┐
  │        │            MCP Server            │      langchain4j @Tool      │
  ├────────┼──────────────────────────────────┼─────────────────────────────┤
  │ 调用方 │ Claude Code（开发时）            │ Gemini（运行时）            │
  ├────────┼──────────────────────────────────┼─────────────────────────────┤
  │ 用途   │ 我帮你生成测试                   │ 应用运行时 Gemini           │
  │        │ PDF、调试、批量造数据            │ 触发业务逻辑                │
  ├────────┼──────────────────────────────────┼─────────────────────────────┤
  │ 协议   │ MCP stdio                        │ Gemini Function Calling     │
  └────────┴──────────────────────────────────┴─────────────────────────────┘

  ---
  如果你真的想让按钮触发 Gemini 生成 PDF

  在 Java 侧写一个 @Tool 方法，让 langchain4j 把它注册给 Gemini：

  @Component
  public class SamplePdfTool {

      @Tool("生成病案首页测试 PDF，可注入质控陷阱")
      public String generateSamplePdf(
          @P("要注入的陷阱名，如 R001、R002，传空字符串表示干净病案") String 
  trap,
          @P("随机种子，传 -1 表示随机") int seed
      ) {
          // 调用 Python 脚本，或把 Python 逻辑用 Java 重写
          ProcessBuilder pb = new ProcessBuilder(
              "python", "-m", "sample_pdf.cli",
              "--count", "1",
              "--out-dir", "data/samples",
              "--error-rate", trap.isEmpty() ? "0" : "1",
              "--traps", trap.isEmpty() ? "" : trap
          );
          // ... 执行并返回路径
          return "data/samples/case_001_" + trap + ".pdf";
      }
  }

  ---
  结论：MCP server 留着给我（Claude Code）在开发时用。Gemini 运行时调工具用
  langchain4j @Tool，两条路互不干扰。
