  1. 2025-12-07 Google 大幅下调过免费档——之前 Flash 是 1500 RPD，现在压到
  250。部分账户/地区报告甚至只有 20–50 RPD，需要登
  https://aistudio.google.com/rate-limit 看自己项目实际配额。
  2. 限额按项目，不按 API key——同一个 GCP 项目下多把 key 共享同一池子。
  3. 配额按太平洋时间午夜重置。
